# odin-recipes

This is a fun beginner-level recipes html project showcasing my ability to use lists, links and images done for The-Odin-Project.

This project builds on the skills learnt in TOP HTML Foundations as well as using Git Basics to have a running record of my work.
Throughout I have made use of different formatting such as using the 'strong' wrap to emphasize words I want to give importance or using ordered and unordered lists conveniently when listing recipe steps or just general information. the 'p' wrap was very useful in making my web page more readable by separating lines in paragraphs.

Overall this project was very enjoyable and tested my newfound knowledge.

More details can be found here: https://www.theodinproject.com/about
